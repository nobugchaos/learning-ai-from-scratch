# 01 手写数字识别（MNIST + 卷积神经网络）

## 这是什么

训练一个小型卷积神经网络，认出 0–9 的手写数字。数据集是 MNIST：6 万张训练图、1 万张测试图，每张 28×28 像素。

## 怎么运行

```bash
python train.py        # 训练 3 轮，约 2 分钟（CPU），第一次会自动下载数据集python predict.py      # 打开画板，用鼠标写数字，实时识别python visualize.py    # 导出网络内部的真实数据，生成可交互网页 viz.html
```

## 文件

| 文件 | 内容 |
|---|---|
| `train.py` | 网络结构（两层卷积 + 两层全连接，约 42 万参数）和训练循环 |
| `predict.py` | 手写画板 / 识别图片文件 |
| `visualize.py` + `viz_template.html` | 可视化：一张图片经过每一层后变成了什么；训练过程中卷积核和预测怎么变化 |

## 实验结果

| 轮次 | 训练准确率 | 测试准确率 | 用时（笔记本 CPU） |
|---|---|---|---|
| 1 | 95.58% | 98.62% | 41s |
| 2 | 98.38% | 99.03% | 41s |
| 3 | 98.82% | 99.07% | 36s |

逐层分析实验（在 2000 张测试图上）：

| 用哪一层的输出做"最近类中心"分类 | 准确率 |
|---|---|
| 原始像素 | 78.0% |
| 第一层卷积 | 82.0% |
| 第二层卷积 | 91.2% |
| 全连接层 | 96.6% |

每过一层，同一个数字的图片在"表示空间"里聚得越紧，越容易分开。
