# 03 迷你 GPT 学写《红楼梦》+ 监督微调

## 这是什么

1. **预训练**：从零训练一个字符级 GPT（Transformer），读《红楼梦》全文，学会"预测下一个字"，然后自己续写。
2. **监督微调（SFT）**：用 150 道带标准解答的物理计算题，把这个"只会写红楼梦"的模型，教成"会按格式答物理题"的模型。

原理和 ChatGPT 一样，只是小了几万倍。

## 怎么运行

```bash
# 1. 下载《紅樓夢》原文（古腾堡计划公有领域版本，繁体，约 2.6 MB）
curl -L -o hlm_raw.txt https://www.gutenberg.org/cache/epub/24264/pg24264.txt

# 2. 预训练：CPU 上用 small 配置约 8 分钟；有 GPU 时自动用 medium 配置
python nanogpt.py

# 3. 监督微调演示：约 2 分钟，生成对比网页 sft_report.html
python sft_demo.py
```

## 文件

| 文件 | 内容 |
|---|---|
| `model.py` | GPT 模型：注意力、Transformer 模块 |
| `nanogpt.py` | 预训练：数据处理、训练循环、续写 |
| `sft_demo.py` | 监督微调：生成问答数据、只在答案部分算损失、微调前后对比 |
| `train_log_cpu.txt` | 预训练日志，含每个阶段的试写 |
| `作品_cpu.txt` | 预训练后以"寶玉"开头续写的 300 字 |

## 实验结果

### 预训练（small 配置，192 万参数，笔记本 CPU 训练 2000 步）

| 步数 | 损失 | 它写出来的 |
|---|---|---|
| 0 | 8.57 | 寶玉身屬牟玷殊6特核絹幔印抵療潛規… |
| 750 | 4.22 | 寶玉見寶釵笑道："你還要見，你活回來… |
| 2000 | 3.85 | 寶玉坐下．尤氏笑道："你這會子怎么！快們要罷。" |

学会了人名、对话格式和书中的腔调，但没学会意思。
检查续写内容：连续 10 个字以上的片段在原书中都找不到，说明它是自己"编"的，不是背的。

### 监督微调（在 30 道没见过的新题上考试）

| | 微调前 | 微调后 |
|---|---|---|
| 答题格式正确 | 0% | 100% |
| 答案算对 | 0% | 23% |
| 答案算对（训练里见过的题） | — | 93% |

- SFT 很快教会了"怎么答"（格式），但没教会"怎么算"：新题的数字大多是编的，格式却完全正确，这就是"幻觉"的缩影。
- 微调后再让它续写红楼梦，冒出了 `寶玉笑道："不用k4×10=10N。"`：新学的内容污染了旧能力，即"灾难性遗忘"。
