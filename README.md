# 从零学 AI（learning-ai-from-scratch）

我一直对数学和物理有一种执念，觉得那才是理解世界的正路。
GPT-3 出来的时候，我没把它当回事，更没有想到，AI 有一天会一路攻进这些我最看重的领域。

后来 GPT-3.5、GPT-4o 接连出现，石破天惊。雏形已经摆在眼前，我却发现门槛太高、无从下手：
能做的只是看懂原理，真正亲手做出来的，只有一些入门级的小项目，离顶会顶刊上的前沿很远很远。
那时候想做点什么，都得自己一行一行手写代码；哪怕只是照着别人的仓库，复现一个最基础的手写数字识别，
光是配环境、装依赖、解决各种报错，就要折腾很久。

现在情况变了。我在做 AI + 物理方向的产品研发，有一份稳定的工作，日常就和 AI Agent 打交道。
于是在工作之余，我也开始用 prompt 驱动 Agent，亲手把一个个 AI 项目做出来：
从入门级的教学项目开始，一步步往前沿走，弄明白它们到底是怎么工作的。

这个仓库就是这段路的记录。每个项目都能直接运行，附上实验结果和我的理解。

> **说明**：本仓库的代码由 AI Agent（Claude）编写；项目方向、实验设计、运行、结果分析和笔记由我完成。

## 怎么运行

需要 Python 3.10 或以上版本。

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows；macOS/Linux 用 source .venv/bin/activate
pip install -r requirements.txt
```

然后进入各项目文件夹，按里面的 README 运行。
数据集和训练好的模型体积较大，没有放进仓库，运行时会自动下载或重新训练。
